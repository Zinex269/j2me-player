Features & limits

Implemented: JAR/JAD import and validation, manifest, icon and API scan, local IndexedDB storage, per-game RMS backend, touch/mouse/keyboard keypad with MIDP key codes, key repeat, display scaling.

Not implemented: Java bytecode execution (no MIDP/CLDC runtime is bundled), audio, 3D (M3G), networking. In the browser, games open in an input-test screen. In the Android app, Play hands the game to the J2ME-Loader runtime (installed separately).

Runtime contract: J2ME.register({running, unsupported:[], async load({game,jar,canvas,width,height,storage}), async start(), pause(), resume(), stop(), keyPressed(c), keyRepeated(c), keyReleased(c)})
